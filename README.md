A program that writes one kind, funny fortune for a houseplant in 120 characters or fewer — a prediction for the plant on the windowsill, about its own future — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

This writes a single line to `/output/entry.txt`. The program is deterministic (byte-identical output on every run), uses no network, and reads no files outside this repository.
